1. 运算定律与性质 / Properties of Operations
定律名称 (Term & Law) 字母公式 (Algebraic Formula) 应用与技巧 (Key Memory Strategy)
加法交换律
Commutative Prop. (+)		 a + b = b + a 两数相加换位置，和不变。
凑整常用 / Friendly numbers: 27 + 73 = 100
加法结合律
Associative Prop. (+)		 (a + b) + c = a + (b + c) 连加分组不改和，优先组合凑整十、整百、整千。
减法性质
Subtraction Property		 a - b - c = a - (b + c) 连续减去两数等于减去和；括号前是减号，去括号要变号。
乘法交换律
Commutative Prop. (×)		 a × b = b × a 黄金组合必背 / Benchmark pairs:
25 × 4 = 100,   125 × 8 = 1000
乘法结合律
Associative Prop. (×)		 (a × b) × c = a × (b × c) 拆数凑整 / Factor decomposition:
25 × 32 = (25 × 4) × 8 = 100 × 8 = 800
乘法分配律
Distributive Property		 (a + b) × c = ac + bc
(a - b) × c = ac - bc		 最高频考点！拆开相乘再相加/减。
逆用为“提取公因数” (Factoring out common factor)。
除法性质
Division Property		 a ÷ b ÷ c = a ÷ (bc) 360 ÷ 8 ÷ 5 = 360 ÷ (8 × 5) = 360 ÷ 40 = 9   (b, c ≠ 0)
商不变性质
Quotient Invariance		 a ÷ b = (a×c) ÷ (b×c)
a ÷ b = (a÷c) ÷ (b÷c)		 被除数与除数同乘或同除以相同非零数，商不变。
陷阱 / Watch Remainder: 余数随之放大或缩小相同的倍数！
2. 最大公因数与最小公倍数的计算 / How to Calculate GCF & LCM
计算方法 (Method) 最大公因数 (GCF / Greatest Common Factor) 最小公倍数 (LCM / Least Common Multiple)
列举法
Listing Method
(适合较小数)		 列出所有因数，挑出最大的公共数：
• Factors of 12: 1, 2, 3, 4, 6, 12
• Factors of 18: 1, 2, 3, 6, 9, 18
→ GCF(12, 18) = 6		 列出两数倍数，找出第一个共同的倍数：
• Multiples of 12: 12, 24, 36, 48...
• Multiples of 18: 18, 36, 54...
→ LCM(12, 18) = 36
短除法 / 梯形法
Ladder Method
(核心高效法)		 “只乘左边” (Multiply Left Column Only)：
用两数的公共质因数连续除，直到商互质。
把左侧除数全部相乘即为 GCF。
• 例：除以 2 得 6, 9；再除以 3 得 2, 3。
→ GCF = 2 × 3 = 6		 “乘成一个 L 型” (Multiply in an 'L' Shape)：
将左侧所有除数与底端最后剩下的商全部相乘。
• 例：左侧为 2, 3；底端为 2, 3。
→ LCM = 2 × 3 × 2 × 3 = 36
两数特殊关系
Special Relations		 • 若 a, b 互质 (Coprime): GCF(a, b) = 1
• 若 a 是 b 的倍数: GCF(a, b) = b		 • 若 a, b 互质 (Coprime): LCM(a, b) = a × b
• 若 a 是 b 的倍数: LCM(a, b) = a
3. 角度、三角形与平面几何 / Angles, Triangles & Geometry
角的分类 / Classification of Angles
  • 锐角 (Acute angle): 0° < θ < 90°
  • 直角 (Right angle): θ = 90°
  • 钝角 (Obtuse angle): 90° < θ < 180°
  • 平角 (Straight angle): θ = 180° (等于 2 个直角)
  • 周角 (Full angle / Revolution): θ = 360° (等于 4 个直角)
三角形定理 / Triangle Properties
  • 内角和定理 (Triangle Angle Sum):
    ∠1 + ∠2 + ∠3 = 180°
  • 两边之和大于第三边 (Triangle Inequality):
    任意两边之和大于第三边 (a + b > c)。
    速判: 较短两边之和大于最长边 / Sum of 2 shorter sides > longest.

1. 多边形面积与立体几何 / 2D Area & 3D Volume
图形 / 几何体 (Shape/Solid) 核心面积 / 体积公式 逆向逆推公式 (Inverse) 易错要点 (Watch Out)
平行四边形
Parallelogram		 A = ah (or bh) a = A ÷ h
h = A ÷ a		 底和高必须垂直对应。
Base and height must be perpendicular.
三角形
Triangle		 A = ½ah = ah ÷ 2 a = 2A ÷ h
h = 2A ÷ a		 切记除以 2！(Divide by 2)
逆向推导必须先乘 2 再除。
梯形
Trapezoid		 A = (a + b)h ÷ 2 h = 2A ÷ (a + b)
a + b = 2A ÷ h		 a: 上底 (Top), b: 下底 (Bottom)。
同样必须除以 2！
长方体
Rectangular Prism		 棱长和: L = 4(l + w + h)
表面积: SA = 2(lw + lh + wh)
体积: V = lwh = Bh		 h = V ÷ (lw)
B = lw (底面积 / Base Area)		 表面积为 6 个面面积之和；
底面积 B = lw。
正方体
Cube		 棱长和: L = 12s
表面积: SA = 6s²
体积: V = s³ = Bh		 s² = SA ÷ 6 棱长扩大 n 倍，表面积扩大 n² 倍，体积扩大 n³ 倍。
容积与体积单位换算 (千进制 / Capacity): 1 m³ = 1,000 dm³ = 1,000,000 cm³  |  1 dm³ = 1 L (升)  |  1 cm³ = 1 mL (毫升)  |  1 L = 1,000 mL
2. 数论核心：因数、倍数、质数与整除 / Factors, Multiples & Divisibility
整除判定规则 / Divisibility Rules
  • 2 的倍数 / Divisible by 2:
    末位为偶数 / Last digit is even (0, 2, 4, 6, 8)
  • 5 的倍数 / Divisible by 5:
    末位是 0 或 5 / Last digit is 0 or 5
  • 3 (或 9) 的倍数 / Divisible by 3 (or 9):
    各数位之和能被 3 (或 9) 整除 / Sum of digits is divisible by 3 (or 9)
  • 4 (或 25) 的倍数 / Divisible by 4 (or 25):
    末两位数能被 4 (或 25) 整除 / Last two digits form a number divisible by 4 (or 25)
  • 8 (或 125) 的倍数 / Divisible by 8 (or 125):
    末三位数能被 8 (或 125) 整除 / Last three digits form a number divisible by 8 (or 125)
公因数与公倍数性质 / GCF & LCM Rules
  • 互质数 / Coprime (Relatively Prime):
    公因数只有 1 / Their only common factor is 1.
  • 若 a 与 b 互质 / If a & b are coprime:
    GCF(a, b) = 1,   LCM(a, b) = ab
  • 若 a 是 b 的倍数 / If a is a multiple of b:
    GCF(a, b) = b,   LCM(a, b) = a
  • 乘积恒等式 / Product Identity:
    a × b = GCF(a, b) × LCM(a, b)
  • 铁律 / Universal Truths:
    1 既不是质数也不是合数；2 是唯一的偶质数。
    1 is neither prime nor composite; 2 is the only even prime.

3. 分数与方程性质 / Fractions & Algebraic Properties
核心性质 (Core Rule) 公式定义 (Formula) 核心用途与法则 (Usage)
分数的基本性质
Fundamental Fraction Prop.		 a/b = (a×c)/(b×c) = (a÷c)/(b÷c)
(b, c ≠ 0)		 分子分母同乘或同除以相同非零数，分数值不变。是约分与通分的唯一依据。
约分与最简分数
Simplifying Fractions		 分子分母同除以最大公因数：
a/b ÷ GCF(a,b)		 分子分母互质的分数叫最简分数 (Simplest form / Reduced fraction)。
通分与异分母加减
Common Denominators		 利用最小公倍数统一分母：
LCD = LCM(b, d)		 异分母分数相加减，先通分化成同分母，再按照同分母分数加减法则计算。
